# Placeholders, not the hotel's assets

The files here come from Timo's design export for VAY-2422 and stand in until the hotel's real
photos and brand font arrive (client Drive folder):

- `*.jpg`: low-res cut-outs of the design mockup.
- `jost.woff2`: Jost (latin subset, weights 300–500), the font the design borrowed. Jost is
  Copyright 2020 The Jost Project Authors (https://github.com/indestructible-type/Jost) and is
  licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).

To replace them, change the imports in `../assets.ts` and delete this folder.
